# M3 组队、决斗、断线重连（草案，待你定）

M1 证明了单刷的手感和反作弊闭环，M2 做出了一个像样的地下城。M3 把它变成多人游戏：
2～4 人组队刷黑风寨、1v1 决斗、掉线或切后台以后能回到局里。

单刷时，别人的输入根本不存在，预测永远对，回滚几乎不发生。多人时，队友的输入要隔一个往返才到，
画面上的队友是"猜"出来的，猜错就回滚。M3 真正要回答的是：

| 编号 | 问题 | 怎么算回答了 |
|---|---|---|
| Q1 回滚手感 | 队友、对手的输入晚一个往返才到，回滚频繁以后，自己的操作还跟手吗？别人的角色会不会乱跳？ | 4 人各 150 ms 延迟时，自己的操作仍然没有延迟；别人的角色被纠正时看着是"滑过去"，不是瞬移（用户试玩） |
| Q2 公平 | 决斗里两边延迟不同，谁先出手由谁说了算？作弊的一方能不能拖垮另一方？ | 决斗的结果只由服务器复算决定；作弊一方被抓后判负，不影响另一方 |
| Q3 断线 | 掉线、切后台、换网络后能不能回到局里，而且不拖累队友？ | 断线 60 秒内重连能接着打；断线期间队友照常打，局不暂停 |
| Q4 成本 | 一台 VPS 同时能跑多少局（每局一个复算 worker）？ | 测出单机并发局数，记进本文档 |

## 内容范围

### 组队

- 2～4 人，用"房间码"组队：一个人建房间拿到 4 位码，其他人输码进来，房主点开始。不做自动匹配。
- 所有人都是剑魂，每人用自己的出战配置（现在配置是整局共用的一份，要改成每人一份）。
- 地下城还是黑风寨，怪的血量按人数加：每多一人 +60%（2 人 160%、4 人 280%），伤害不变。
- 门：任何一个活着的人走进门，全队一起进下一间（引擎现在就是这样）。
- 倒下：倒下的人看着队友打（镜头跟最近的活人）；清完一个房间，倒下的人以 30% 血站起来。全员倒下才算失败。
- 药水：谁先踩到谁喝。
- 评分：全队一个评分（用时、全队最大连击、全队被击次数），被击的标准按人数放宽。
- 掉落：每人各抽各的（个人掉落），互相看不到；作弊被抓的那个人什么都不拿，其他人照常。
- 画面：队友身上淡一些、头顶写名字（先用设备 ID 后四位），血条显示在左上角自己的血条下面。

### 1v1 决斗

- 也用房间码。一个单独的竞技场（一间房，没有怪），两边都是剑魂，各用自己的出战配置。
- 3 局 2 胜，每局 60 秒；时间到按剩余血量百分比判。
- PvP 修正（只在决斗里生效）：伤害 ×50%；对人的浮空衰减比打怪快（每段 30%）；受身可用；起身无敌 0.5 秒。
  具体数值先跑起来再调。
- 没有掉落，只显示胜负。

### 断线重连

- 断线、刷新页面、切后台太久都算掉线。服务器继续推帧，掉线的人输入为空（角色站着不动，会挨打）。
- 60 秒内用同一设备 ID 回来，就接着打；超过 60 秒视为离开，角色留在原地（组队时算倒下，决斗时判负）。
- 回来时不从第 0 帧重放：服务器把复算 worker 最近一次进房间时的快照发给客户端，客户端从那里快进到当前帧。

## 技术范围

### engine/

- `RunConfig` 改成每人一份配置（`loadouts[]`），人数决定怪的血量倍数；决斗模式（`mode: 'duel'`）带 PvP 修正和回合计分。
- 主角之间的攻击：组队时互相打不到，决斗时能打到。
- 倒下的人清房后起身；全员倒下才失败。
- 机器人能多人打：几个 bot 一起清黑风寨、两个 bot 互相决斗。
- 黄金回放：4 人黑风寨一局、决斗一局。

### server/

- 大厅：建房间、输码加入、准备、开始；房间里谁在、谁准备好了。
- `Run` 从一个连接改成多个：每人一个 `owner` 号，指令按人落帧，状态校验按人记；谁的 hash 和复算对不上就只标记谁。
- 断线：连接断了不结束局；记下设备 ID，重连时发配置、快照、快照之后的全部已定帧。
- 并发压测：一台机器同时跑 N 局 4 人局，看 CPU 和内存。

### client/

- 大厅界面：建房间 / 输码 / 准备 / 开始；决斗入口。
- 预测别人的输入：沿用对方上一帧的按键（现在只有自己的输入，不用猜）。确认帧到了、和猜的不一样就回滚。
- 回滚平滑：别人的角色被纠正时，画面位置在约 0.1 秒内滑到正确位置，不瞬移；自己的角色不平滑（自己的输入从来不会猜错）。
- 重连：断线后自动重连，收到快照后快进，快进时显示"重新连接中"。

## 不做

自动匹配、好友、聊天、观战、排位分（M3 只要能打）；第二个职业；装备和养成（M4）；微信构建；拆服务。

## 验收标准

- 4 个机器人各带不同延迟（0 / 50 / 150 / 300 ms）联机通关黑风寨，每人的每个检查点都和复算一致，每人都拿到掉落。
- 4 人局里一个人开 `?cheat=dmg`：只有他被标记、拿不到东西，其他三人照常通关拿掉落。
- 两个机器人决斗打完 3 局，两边客户端和服务器的胜负一致。
- 一个人断线 30 秒后重连，接着打完，结果和复算一致；断线期间队友照常打。
- 性能：4 人、每人 150 ms 延迟下，回滚重算 20 帧 < 8 ms（中档 PC 的 Chrome）；单台 VPS 并发局数测出来并记录。
- 用户试玩（两个以上标签页或设备）：自己的操作不卡；队友不乱跳；决斗打起来有来有回。

## 顺序

1. **引擎多人**：每人配置、怪的血量倍数、多人倒下与起身、机器人多人；4 人黄金回放。
2. **服务器多连接 + 大厅**：房间码、按人落帧和校验、个人掉落；客户端预测别人的输入、回滚平滑；4 个机器人端到端测试。
3. **断线重连**：服务器发快照、客户端快进；端到端测试断线 30 秒。
4. **决斗**：竞技场、PvP 修正、回合计分；两个机器人对打的测试。
5. **压测**：单机并发局数。
6. 用户试玩，按反馈调。

每一步结束都跑 `npm run check`，并请你在游戏里看一次再进下一步。
