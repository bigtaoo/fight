# 单机版上架 CrazyGames（草案）

2026-10-15 定：先做单机版，上 CrazyGames 做基础测试（Basic Launch）；联机（M3）等基础测试过了再加。

2026-10-15 再定：**先只做上架必需的，新功能（更多关卡、装备、新骨骼）等基础测试验证了玩法再加**。

2026-10-15 三定（取代上一条）：**先把内容和循环做完（20 小时以上）再上架**，见 [CONTENT.md](CONTENT.md)。
本文已做的平台接入照用；第 6 步自查、上架材料放到 CONTENT.md 做完之后。
单机版不依赖游戏服务器（构建时就不连）；唯一往外发的是流失数据的匿名事件，发不出去也不影响游玩。

要回答的问题只有一个：**陌生玩家愿不愿意玩下去**。CrazyGames 的 Basic Launch 给一小段时间的真实流量，
不放广告，看平均游玩时长和留存，再决定要不要 Full Launch。所以这一版不加新玩法，只补齐"能上架"缺的东西，
外加能看出玩家在哪里流失的数据。

## 平台硬要求（来自 docs.crazygames.com，2026-10-15 查）

## 范围

### 1. 剩下的角色换成新骨骼（推迟到基础测试之后）

主角、弓手的 3D 衍生骨骼已经确认没问题。山贼（精英山贼也用它）、盾兵、寨主按同一流程重做；
主角、弓手的 3D 衍生骨骼已经是默认（2026-10-15，`?oldrig` 在开发构建里看旧的）；全部做完后删掉旧骨骼和 `frames` 播放方式、`?archer3d`。上架后的截图、封面都靠这一步。

### 2. 单机构建

- 构建目标 `crazygames`（已做）：`npm run build:cg -w client` 出到 `client/dist-cg`，相对路径，不连服务器；
  本机看：启动配置 `client-cg`（`vite preview`，端口 5191）。首包 11 MB、120 个文件（加了声音以后）。
  调试参数（`?bot`、`?cheat`、`?bench`、`?seed`、`?dungeon`、F1 判定框等）只在开发构建里有（已做，`main.ts`）：
  发布构建（CG 包和 f.gamestao.com）一个都不读。
- 单机掉落（2026-10-15 定，已做）：本地按服务器同一张掉落表抽（表挪到 `server/lootTables.ts`，服务器和客户端共用），
  存进本地背包（`client/src/net/localLoot.ts`，localStorage 的 `dnf.localBag`，以后换成 SDK 的 Data 模块）。
  本地背包和联机背包是两回事：以后上联机，联机背包从零开始，本地的物品不带过去，"掉落只由服务器决定"在联机部分仍然成立。
  练习关、倒下的局不掉。结算界面显示"获得 xxx"，右上角列出背包。
- 失去焦点、页面隐藏时停住模拟（已做）：单机直接不推进 session，回来要点"继续"。联机时服务器时钟照走，菜单打开但游戏不停。

### 2b. 更多关卡（草案；推迟到基础测试之后）

现在只有黑风寨一张图（3～5 分钟），陌生玩家打完就没东西了。目标：**4 张图、普通和困难两档，约 30 分钟以上的内容**，
而且尽量不新增怪物美术（每种新怪、新 Boss 的骨骼和招式成本最高）。

| # | 地下城 | 房间 | 主打 | 精英 / Boss | 新东西 |
|---|---|---|---|---|---|
| 1 | 黑风寨（已有，新手引导） | 6 | 山贼、弓手、盾兵 | 精英山贼 / 寨主 | — |
| 2 | 竹林伏击 | 5，一条岔路 | 弓手多，树后埋伏（进房时从两边刷出） | 精英弓手（三连射、后跳更勤）/ 无 Boss，最后一间守关的是两只精英 | 竹林背景；分波刷怪 |
| 3 | 黑风岭 | 6 | 盾兵阵（2～3 只一起推进）、山贼冲锋 | 精英盾兵（盾击连两下）/ 寨主二次登场：一开局就是二阶段的快速招式，血更多 | 山岭背景 |
| 4 | 聚义厅夜袭 | 4 | 混编，怪更密 | 两只寨主前后夹击 或 新 Boss（见待定） | 夜景沿用聚义厅 |

- **解锁**：通关上一张才开下一张；每张记最好评分、最快用时。
- **困难档**：任何一张通关后开放，怪的血量 ×1.6、伤害 ×1.5，评分标准更严，掉落从更高的表抽。DNF 的普通 / 冒险 / 勇士 / 王者就是这个做法，内容翻倍、几乎零美术成本。
- **精英怪**：沿用"借骨骼 + 放大 + 染色"（精英山贼就是这样做的），精英弓手、精英盾兵只加数值和一两个招式变化。
- **引擎**：地下城加 `scale`（血量、伤害倍数，进 hash）；房间加分波刷怪（清掉第一波再出第二波）；新怪种 `eliteArcher`、`eliteShield`。`ENGINE_VERSION` 升级，黄金回放每张图各一局。
- **客户端**：选关界面（一幅横向画卷，四个地点，点一下进；锁住的灰掉），结算后"下一关 / 再来一局 / 返回画卷"。
  打开游戏第一次直接进黑风寨（满足开局即玩），之后进画卷。
- **背景**：竹林、山岭两套新的四层背景，走 `tools/bg_layers.py` 现成的流程。
- **掉落**：每张图一张通关掉落表，新增几件物品（仍然只能看、不能穿戴）。
- **机器人**：每张图普通档都要能通关（端到端测试按图各跑一局）。

做法照旧：先用色块把新怪和分波调好，你试玩，再出背景和精英的染色。

### 3. 游戏流程（开局即玩，最多一次点击）

- 打开 → 加载 → 直接进黑风寨，引导文字照旧（第一次玩出现，之后可跳过）。
- 通关或倒下 → 结算界面：评分、用时、连击、掉落；按钮"再来一局"和"挑战寨主"（现在的 `?dungeon=hall`）。
- 右上角一个暂停按钮：继续、重新开始、声音开关、语言。
- 进度存档：是否通关过、最好评分、最快用时（用 SDK 的 Data 模块；没有 SDK 时用 localStorage）。

**已做（2026-10-15）**：
- 暂停：右上角按钮、P 键（Esc 是浏览器保留键，CG 不让用）、窗口失焦或页面隐藏自动暂停；暂停时声音、音乐一起停，
  手指和按键全部松开。暂停菜单：继续、重新开始、声音开/关。鸣谢不放在游戏里（见 §4）。`client/src/game/menu.ts`。
- 结算按钮：总有"再来一局"；黑风寨通关过以后多一个"挑战寨主"；在聚义厅里是"回黑风寨"。
- 存档：`client/src/game/progress.ts`，localStorage 的 `dnf.progress`，每张图记通关次数、最好评分、最快用时；
  结算界面多一行"最佳"，破纪录标"新纪录！"。以后换成 SDK 的 Data 模块（和背包一起）。
- 左上角原来的"♪ 声音"挪进了暂停菜单；M 键照旧。小地图左移，给暂停按钮让位。

### 4. 声音

**已做（2026-10-15）**。来源：网上开源授权的（CC0 优先，CC BY 就署名），音效和音乐都是；不用 AI 生成的音乐。

- 文件在 `client/public/audio/`（`sfx/` 30 个、`music/` 2 首），每个旁边同名 `.txt` 记来源、作者、授权；
  总署名是单独的页面 `client/public/credits.html`（随包发出，游戏里不链接）。转换脚本思路：ffmpeg 去头尾静音、峰值归一、单声道 96 kbps mp3；音乐 96 kbps 立体声。
- 映射 `client/src/game/sounds.ts`（纯函数，有测试）：普攻挥空 swish、重招 slash、命中 hit / 重击 heavy、
  格挡刀剑相击 clang、霸体 armor、箭 swish 升调、剑气 wave、跳砸 quake + 碎石、跳 / 落地 / 倒地、
  怪死 die、主角倒下 herodown、喝药 drink、寨主二阶段怒吼 roar、清房 clear、通关 win。主角的挥砍比怪的响。
- 播放 `client/src/game/audio.ts`：音效 WebAudio 预解码；音乐用 `<audio>` 流式接进 WebAudio（整首解码要上百 MB），
  道中 / Boss 房（房里有 boss 类怪）之间淡入淡出，倒下后停。第一次点击或按键解锁（iOS）；页面隐藏时全停；
  同一组 45 ms 内不重复；音高随机 ±6%。
- 静音：M 键或暂停菜单里的声音开关，存在 localStorage `dnf.mute`。暂停由 Game 统一调 `SoundPlayer.pause`，以后 SDK 的广告静音也走这里。

### 5. 多语言与原创名

- 所有界面文字、引导、技能名、物品名进语言表（`client/src/i18n/`），英文、中文两份。
- 技能名换成原创：三段斩、猛龙断空斩、上挑、破军升龙击、拔刀斩、幻影剑舞 → 新名字；引擎里的招式 id 不变。

**已做（2026-10-15）**：
- `client/src/i18n/`：`en.ts` 是基准表，`zh.ts` 必须一键不差（类型检查 + 测试，占位符也要一致）。`t(key, {变量})`；
  `{KeyX}` 这类占位换成玩家键盘布局上的实际键名。
- 选语言：暂停菜单里选过的（`dnf.lang`）优先，否则看语言区域（现在是浏览器语言，接 SDK 后换成 SDK 的 `locale`），
  中文区域显示中文，其他一律英文。开发构建可用 `?lang=en|zh`。
- 暂停菜单多一个语言按钮（显示要切换到的语言："English" / "中文"），切换立刻生效，不用重开。
- 技能新名（中 / 英，按钮上显示）：三段斩 → 叠浪 / Tide，猛龙断空斩 → 奔雷 / Rush，上挑 → 挑月 / Lift，
  破军升龙击 → 破山 / Breaker，拔刀斩 → 一线 / Flash，幻影剑舞 → 泼墨 / Inkstorm。
- 地名、Boss、物品原本就是自起的（黑风寨、聚义厅、黑风寨主、流云袍……），只补了英文：Black Wind Fort、Black Wind Chief 等。
- 物品名按 id 查表；服务器发来的中文名只在表里查不到时兜底。
- 游戏名定为 **Brushblade / 笔锋**（2026-10-15）：标签页标题跟着语言变（`game.title`），credits.html 也带上。
  上架和介绍里都不提 DNF（别人的商标）；仓库名、`dnf.*` 存档键不用改，玩家看不到。

### 6. 接 CrazyGames SDK v3

- `index.html` 引入 SDK 脚本；没有 SDK（本地开发、自己的站）时全部空操作。
- `loadingStart/Stop` 包住资源加载；进入战斗时 `gameplayStart`，暂停、结算界面时 `gameplayStop`；
  打赢寨主时 `happytime`。
- Data 模块存进度；`locale` 选语言。

**已做（2026-10-15）**，`client/src/platform/index.ts`：
- SDK 脚本只在 CG 构建的页面里（`vite.config.js` 插入 `<head>` 最前）；没有 SDK、启动失败、超过 5 秒没启动、
  或 SDK 报 `disabled`（别的域名）时，所有调用都是空操作，存档照旧用 localStorage。
- `main.ts`：先启动 SDK，再 `loadingStart`，按 SDK 的 `locale` 选语言，载完 `loadingStop`。
- 游玩开始/停止：每帧算"在玩吗"，变了才告诉平台。暂停面板（玩家自己打开的）和结算界面算停；
  窗口失焦、页面隐藏自动暂停的不算停（平台文档要求：失焦由平台自己处理，别发 stop）。
- `happytime`：只在黑风寨第一次通关（打赢寨主），或刷新最佳评分 / 最快用时时。
- 背包、进度存进 SDK 的 Data 模块（登录玩家跨设备同步）；Data 里没有、localStorage 里有的键第一次读时搬过去。
  语言、静音、流失数据的设备 id 仍在 localStorage（只跟这台设备有关）。
- 平台的静音设置（`settings.muteAudio`，含之后的变化）优先于玩家自己的声音开关。
- 本机看：`client-cg` 预览在 localhost 上，SDK 是 `local` 模式，控制台会打出每次调用；`?muteAudio=true` 试平台静音。
- 提交时要勾选 "Progress Save"，否则 Data 模块不生效。

### 7. 流失数据

平台只给总时长和留存，看不出玩家在哪一步走掉。（2026-10-15 定，已做）

- 发到 daydayup 那台 VPS 上已有的 dnf 服务器：`POST https://fs.gamestao.com/events`，每天一个
  `data/events-YYYY-MM-DD.jsonl`（`server/src/events.ts`）。push 到 main 后随服务器一起部署。
- 只有匿名事件：每次打开一个随机 id；`open`（是否第一次、是否触屏、浏览器语言）、`start`（第几局）、
  `room`（进第几间）、`end`（通关/倒下、在哪间、评分）、`leave`（页面隐藏时：玩了多久、停在哪间）。
  不收个人信息，不需要弹同意框。客户端 `client/src/net/telemetry.ts`，用 `sendBeacon`，攒一批再发。
- 开发构建、`?bot`、`?notelemetry` 不发。
- 看报告：
  `ssh blightbloom 'cat /home/deploy/fight/data/events-*.jsonl' > events.jsonl`，
  然后 `npm run funnel -w server -- ../events.jsonl`：访问数、开局率、再来一局的比例、时长中位数、
  每间房的到达率 / 死亡数 / 离开数、评分分布。
