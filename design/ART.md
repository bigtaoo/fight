# 美术：水墨风 + AI 出图

## 方向

- 水墨为主，**朱砂红是主角专属的强调色**（围巾等），敌人只用墨色、靛青、灰，不出现红色
  （沿用 standing"主角暖色、敌人冷色"的可读性规则）。
- 侧面视角朝右，向左时水平镜像。
- 游戏内尺寸（1080p 逻辑单位）：主角高约 240，杂兵 200～260。

## 出图流程（沿用 standing）

1. prompt 写成 `.txt`，放在产出图旁边。
2. `tools/generate_image.sh <out> <prompt.txt>`：Mistral Agents API 调用 FLUX 文生图（约 1024×768）。
   `tools/edit_image.sh <in> <out> <prompt.txt>`：以参考图做编辑，输出保持输入比例。
   密钥在 `~/.vibe/mistral_curl_key*.conf`，`mistral_failover.sh` 负责限流时轮换 key。
3. 人工挑选；落选的写清原因。
4. 抠图：水墨用 `tools/ink_cutout.py`，而不是 standing 的 `cutout.py`。
   后者把与边缘连通的浅色低饱和像素当背景，会吃掉墨晕和飞白。
   `ink_cutout.py` 让人物主体保持不透明（人群重叠时不会互相透过去），主体外的墨迹按纸色做 color-to-alpha，保留半透明。
5. 可读性：`tools/ink_scene_test.py` 把人物按 240 和 120 两种高度，贴到浅纸、中灰墨晕、深色洞窟三种地面上。

## 动画（沿用 standing）

- 主角、精英、Boss：剪纸骨骼。先 edit 出一张侧面 A-pose（四肢离开身体）→ 拆件 → `.tao`。
  换装、时装只需替换部件贴图。
- 杂兵：单张图做软边区域变形，烘焙成帧序列（standing `tools/bake_mob.py`）。
- 判定框在 animator 里逐帧编辑，导出给引擎；渲染骨骼不参与判定。

水墨特有的风险：飞白、墨晕跨过关节，拆件后转动关节时会露出断口。拆件那一步要专门验证。

## 风格轮次

### R1（`art/style_r1/`）

同一个角色（江湖剑客，侧面朝右，持剑低姿态），四个方向：

| 文件 | 方向 |
|---|---|
| `a_xieyi` | 写意：粗放笔触、飞白、大量留白，黑灰墨 + 朱砂 |
| `b_gongbi` | 工笔淡彩：细匀墨线 + 透明矿物色（靛青、石灰、浅赭）|
| `c_brushcel` | 笔触描边 + 平涂：粗细变化的墨线外轮廓，平涂墨灰/靛青/米白，一层硬边墨影 |
| `d_pomo` | 泼墨剪影：几乎全黑的墨色剪影，用留白线勾出五官、手、衣褶、剑刃 |

可读性对比：`art/style_r1/scene_test.png`。

观察：

- 四张都没画成纯侧面，而是 3/4 侧身。DNF 本来就是这样，保留。
- FLUX 不听"白底、无落款、无地面阴影"：a 加了黑边、落款和印章；b 是灰底；b、c、d 都有地面阴影或墨池。
  `ink_cutout.py` 已能处理灰底、黑边、地面阴影，但落款和印章只能重新生成或手工擦掉。
- a 写意：最像水墨画，但袍子的墨晕是半透明的，人群重叠时会糊在一起；边缘破碎，拆件难度高；出图不稳定。
- b 工笔：画出来是普通平涂插画，没有工笔特征。淘汰。
- c 笔触平涂：最干净，最好拆件，但看起来像日系动画，墨味最弱。
- d 泼墨剪影：轮廓最强，在浅纸和中灰上都很醒目，朱砂红非常跳；剪影内部细节少，拆件接缝反而容易藏。
  缺点是在深色背景上几乎消失。

**已定（2026-10-08）**：

- 角色走 d（泼墨剪影）。
- 世界观为"画卷世界"：场景永远是浅到中灰的纸面，不出现纯黑背景；夜晚、洞窟用靛青灰墨晕表现，保持中等亮度。
- 主角为浓墨 + 朱砂；敌人用较淡的灰墨、靛青，不用纯黑，与主角拉开明度差。
- 所有角色都画成朝右，游戏里镜像得到朝左（FLUX 不听"朝左"）。

### R3 骨骼（`art/rig_r3/`，2026-10-08）

用户反馈 R3a 走路是"滑"的（贴图脚不动），于是提前做骨骼。主角已换成骨骼动画；山贼、木桩仍用 R3a 姿势图。

流程（每一步都可重跑）：

1. `python -I tools/mannequin.py art/rig_r3/mannequin.png art/rig_r3/mannequin_joints.json`：代码画灰色 A-pose 人偶。
2. `tools/edit_image.sh mannequin.png hero_apose_X.png hero_apose_X.txt`：FLUX 在人偶上画剑客。
3. 选定的图镜像成朝右，存为 `hero_apose.png`。
4. `python -I tools/draw_sword.py art/rig_r3/sword.png`：代码画剑。
5. `python -I tools/split_parts.py art/rig_r3/split.json art/rig_r3/parts`：按多边形拆成 16 块，`parts/preview.png` 是拼回图和爆炸图。
6. `python -I art/rig_r3/anims.py` 生成 `hero_tao.json`（动画）→ `python -I tools/pack_tao.py art/rig_r3/hero_tao.json art/rig_r3/hero.tao client/public/art/hero`。
7. 检查：`tools/pose_test.py`（`rig.json` 里的测试姿势）、`tools/anim_sheet.py`（按客户端的采样规则把每段动画画成联络表）；游戏里 `?zoom=3` 镜头跟拍主角。

观察：

- 第一轮人偶头太大（约 5.5 头身），FLUX 三张都画成了小孩（`r0/`，弃用）。人偶改成 7.5 头身后都是成年人。
- edit 会保留人偶的大致轮廓，但不严格：手臂收拢了一些，四张里有三张朝左（镜像即可）。
- 选 `hero_apose_D.png`：四肢和身体之间的空隙最清楚，腿分得最开。B/C 朝左、手臂贴身；E 画成了短裤。
- 风格比 R1 的 d 更"平"：剪影干净、墨块均匀，少了泼墨的湿笔感，但拆件和转关节都很干净。墨迹感暂时靠动态墨点补。
- FLUX 不按要求空手画剑会画乱，所以剑是代码画的独立部件（挂在前手上），挥刀时只转手臂和剑。
- 拆件的遮挡区（被袍子、躯干盖住的大腿、肩、肘）用该部件最深的墨色平涂，不用 inpaint：剪影内部几乎全黑，inpaint 会把边缘的浅色和灰色衣褶拖进来。
- 骨骼：躯干、头、围巾、腰带、袍子、前后上臂/前臂/手、剑、前后大腿/小腿，共 17 根骨骼。

客户端（`client/src/game/bodyView.ts`）：

- 运行时从 standing 移植（`client/src/game/tao/`），加了 `seek()`：直接设定片段时间，而不是按真实时间播放。
- 招式片段的时间 = 状态内 tick（hitstop 时不走），所以刀在判定帧上落下，打中时跟着停住。片段关键帧用 tick 写，对齐 `engine/content.ts` 的帧数据。
- 走、跑的片段时间 = 走过的距离 ÷ 一个循环的步幅（走 176、跑 250 世界单位），所以脚不会滑。
- 跳跃按竖直速度在"上升/下落"两个姿势间插值；浮空翻滚仍在代码里整体旋转。
- `?poses` 切回 R3a 姿势图对比。

动作张力（用户反馈第一版出剑"很平、没力道"，不如 R3a 姿势图）：

- 原因：人站得笔直、两腿并拢，只有手臂在挥；收刀时剑尖指地、手臂缩在身前。R3a 的图全是低重心大弓步，整个身体压进刀里。
- 改法（`anims.py`）：待机改为低重心守势；出招时前腿弓、后腿蹬直，躯干扑向刀的方向，后手往反方向甩开；起手先向后仰蓄力一帧，刀一两帧内挥过去，收刀时手臂打直、剑斜指前下方，保持几帧再慢慢收回。打中那一帧是 hitstop 定格的那一帧，要是最有力的剪影。
- `pose()` 默认自动压低 root，让较低的那只脚贴地（宽站姿会下沉而不是悬空）；跑、跳、起身这类离地或跪姿用 `plant=False`。
- 受击的淡入改为和招式一样快（0.04 秒），否则"被打得一甩"会被抹平。
- 第二轮（用户："好了很多，但张力还不够，剑太短"）：打中帧后手完全甩直，和剑连成一条长斜线；弓步更开；袍摆向后拖（`robe`）；整个人比脚多冲出去一点（`root` 的 x，纯表现，不动判定）；蓄力帧更往后仰。
- 剑太短的真正原因：代码画的剑按握把放进原画坐标后，剑尖伸出了原画画布，被裁掉了大半。`split_parts.py` 现在给代码画的部件留足边距。剑长改为 820（约身高的 3/4）。

拆件穿透（用户："胸口有很多白点"）：

- 盖在别的部件上的部件（腰带垂穗、腰带结、围巾）被从袍子、躯干里挖掉了，一甩开就露出背景。袍子、躯干在这些位置补了 `hidden` 平涂。
- 衣服上的白色镶边（领口、下摆）被去纸当成纸变半透明。`split_parts.py` 现在把剪影内部（含小的封闭孔）一律设为不透明、保留原画颜色，只有外轮廓留柔边。
- 下摆白边横穿整条腿，膝盖处的补洞被剪影裁掉，弯腿时裂开。新增 `caps`：不受剪影限制的关节盖（膝盖用圆盘）。
- 检查方法：把联络表的底色换成纯蓝（`tools/anim_sheet.py` 里 `render()` 的 `paper_rgb`），任何穿透都会一眼看出来。

已知问题：袍子下的大腿是平涂色块，大幅迈步（突进、奔跑）时能看出来；前手是张开的，握剑不像；躯干只能在腰部弯折，前倾过大时像驼背。山贼、木桩还没上骨骼。
