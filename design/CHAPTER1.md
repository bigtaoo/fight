# 第一章：千里江山（草案，2026-10-22）

世界观、三人定稿见 [WORLD.md](WORLD.md)。本章从零设计，不受之前测试资源（黑风寨、山贼、旧主角）的限制，
按最终效果来定。它取代 [CONTENT.md](CONTENT.md) 里旧的章节表和故事。

## 目标

第一章就是游戏给人的第一印象，也是新手引导。没有特色、勾不起探索欲，后面做得再多也没人看。

- 第一眼就看懂"我在一幅活的画里"。
- 让人想去看"那幅画里面是什么"。
- 打完一章，心里留一个大疑问。

### 卖点不能只是"恢复颜色"

"墨吃掉颜色、打赢恢复颜色"大神（Okami）已经做过了：同样是水墨、毛笔、让被诅咒的地方重新开花。
恢复颜色保留，但只当每个房间、每一节结束时的奖励画面。真正的钩子要是只有"活在画卷里"才成立的东西：

1. **画中有画**（核心）：画里的屏风、团扇、挂轴、瓷瓶纹样都能走进去，每一幅都是另一个画种的小世界。
   玩家很快会意识到"看到的每一幅画都可能进得去"，探索欲是自己长出来的。后面的新区域也从这里接：新画种 = 走进一幅新画。
2. **印与题跋**：古画上盖满历代收藏家的印、写满题跋。在画中江湖里，印是外来的力量，精英和 Boss 是活过来的印；
   印压住的地方藏着被盖住的原画（隐藏路线）。题跋是历代看画人留下的话，作为世界观碎片收集。
3. **画外有人**（悬念）：偶尔透过纸背看到画外：烛光、巨大的影子、翻动画卷的手。第一章结尾整幅画被人提起来，
   纸透光，外面站着一个看不清的人影。画圣是失踪了，还是就在外面？看画的人是谁？这个疑问撑起主线。

## 结构：一章是一幅画，一节是一局

| 层级 | 是什么 | 规模 |
|---|---|---|
| 大章 | 一幅画（一个画种） | 10 节，约 40～60 分钟 |
| 小节 | 一次进图 = 一局 | 4～6 个房间，3～5 分钟 |
| 房间 | 一屏战斗 | 清完恢复颜色 |

- 一节 3～5 分钟是手机和网页一局的长度，随时能停。
- 一幅画里有几个地点（江村、栈道、宅院、渡口、山寺、拖尾），各节换着组合，背景复用。
- 主角往**右**走（照横版游戏的习惯，不照手卷从右往左的展开方向）。
- 画框永远在画面里：上下露出装裱的绫边，镜头不越出画卷；卷首和拖尾是一章的起点和终点。

**上线测试**：做完三章。

## 英雄解锁

| 时机 | 英雄 | 剧情 |
|---|---|---|
| 开局 | 剑客 | 画圣最后几笔画出来的人，第一个"被画出来"的就是他 |
| 1-5 通关 | 石狮 | 救下守宅门的石狮（见 1-5） |
| 1-10 通关 | 墨斗 | 拖尾里裱着一页界画图样，墨斗被伪印封在上面（见 1-10） |

- 解锁之前先让人看到：1-4 就听到狮吼、远远看到宅门；1-9 就看到拖尾里那页图样和一动不动的木偶。玩家是"想救它"，不是等系统送。
- 解锁后每节开始前选英雄；打过的节可以换人重打。

### 1-1 落笔（新手教程，约 3 分钟）

| 间 | 发生什么 | 教什么 |
|---|---|---|
| 1 白纸 | 全白。按任意键，一笔飞白画出剑客；往右走，前面的山水一笔笔画出来，先勾线后上色 | 移动、跳（5 秒内第一个输入） |
| 2 江村 | 青绿的村子，渔夫撑船、孩子放风筝。墨从画卷上沿渗下来，三个村民变成弱小的墨怪 | 普攻、连招 |
| 3 村口 | 墨怪变多，其中一只先抬手预警再重击；地上有药 | 闪避、捡药 |
| 4 晒谷场 | 大墨怪（墨蚀的樵夫）。开打前笔在剑上补一笔，学会第一个技能；打赢后整个村子的颜色化开回来 | 技能；第一次"打赢 = 恢复颜色" |

- 结尾：村里的屏风开始往外渗墨，镜头停在屏风上，接 1-3 的画中画（1-2 先打完江村其余部分）。
- 操作提示不弹 UI 框，用毛笔字写在画卷纸面上，像画上的题字，写完慢慢淡掉。

### 1-5 宅门：墨狮

石狮子总是一对：雄狮踩绣球，雌狮护幼狮。宅院已经被墨吞掉，雌狮整只被墨蚀，守在门前；雄狮被墨链锁在门柱上。
小 Boss 是**墨狮**（被墨蚀的雌狮）。打赢后墨链断开，雄狮挣脱，跟着上路，要把伴侣找回来，这是它的"缺"之外的个人线。
墨狮复用石狮的骨骼，换墨色、换招式，成本低。

### 1-10 落款：伪印

- 画卷末尾本该盖画圣的印，现在那里是墨凝成的一方巨印，活成一头石印兽。
- 攻击就是盖章：地上先浮出印文的方形轮廓当预警，然后重重盖下，留下一个墨方块（短时间的墨蚀地面）。
- 伪印同时压在拖尾那页界画图样上。打碎它，图样上的墨线亮起，墨斗站起来。
- 落款位是空的：画圣不见了。最后整幅画被人提起来，纸透光，外面站着一个人影。第一章完。

## 本章引入的世界规则

- **墨蚀地面**：灰黑的地，站上去慢慢掉血、减速；房间清完就消失。
- **留白**：没画完的纸面就是坑和墙，地形边界不另做。
- **画中画**：入口是一幅画，进去就是另一个画种的房间（引擎里只是房间图上的一扇门）。
- **印**：压住路的印可以打碎，下面是隐藏路线。
- **颜色恢复**：只是奖励反馈，不是数值。
