# 世界观与角色（草案，2026-10-22）

## 一句话

在一幅活着的画卷里战斗。

## 设定

- 世界是画圣画的一幅长卷。画中的山水、城池、人物、器物都是活的。
- 画圣失踪后，画卷开始"走墨"：墨溢出线条，吞掉画里的颜色，这叫**墨蚀**。
  被墨蚀的人和物变成灰墨色的怪物，被墨蚀的地方褪成水墨，最后变成空白。
- 主角们是画里仅存的、还保有颜色的人，叫**执笔人**。他们一路打过去，把被墨蚀的地方"画回来"。
- 区域按画种划分：山水长卷（序章）、界画城池、工笔宫殿、敦煌壁画、山海经异兽图、市井风俗画……
  新区域、新角色都从新的画种里来（"画中有画"：走进画里的一幅画）。第一章是青绿山水长卷《千里江山》，见 [CHAPTER1.md](CHAPTER1.md)。

## 美术规则：水墨是"笔法"，不是"调色板"

画卷原本是彩色的（青绿山水、工笔重彩、壁画），墨蚀是颜色被墨吞掉。

| 层 | 风格 | 饱和度 |
|---|---|---|
| 背景（被墨蚀） | 水墨晕染、纸底、雾、留白 | 低 |
| 背景（已恢复） | 青绿山水、淡彩 | 中 |
| 玩家角色 | 工笔重彩 + 墨线描边，每人一个主色 | 高 |
| 敌人 | 灰墨身体，墨蚀处发黑紫，留一处原来的颜色 | 中低 |
| 精英、Boss | 墨蚀 + 一个刺眼的颜色 | 中高 |
| 特效 | 墨迹、飞溅 + 朱砂、金色高光 | 高对比 |

- 清完一个房间，背景从水墨晕染回彩色：既是通关反馈，也是截图卖点。
- 敌人以后整体降饱和，高饱和留给玩家角色。
- 辨识度原则：轮廓、主色、动作语言三样都不重复；剪成纯黑影也能认出来。

## 初始三人：人、兽、器

开局只有剑客；1-5 通关得石狮，1-10 通关得墨斗（剧情见 CHAPTER1.md）。

三人各有一个"缺"，主线是三个各有所缺的画中人一起去找画圣。

定稿概念图（2026-10-22），都在 `art/heroes/concept/`，prompt 是同名 `.txt`：

### 剑客（人）——对应鬼剑士

- 中国武侠的侠客，人形。武器：长剑。
- 轮廓：瘦高（约 7.5 头身）。主色：朱砂 + 墨黑。
- 缺：来历。他是画圣最后几笔画出的人，不知道自己为什么被画出来。
- 定稿：草编尖斗笠压低，整张脸藏在阴影里，只露下巴和红系带（"无脸"也呼应他没有来历）。
  朱红大袖外袍、下摆撕成飞白一样的碎条往后飘；黑色交领内衫、黑灯笼裤、黑护臂和靴；
  黑腰封配金扣，垂红色流苏绳；直身长剑、金色剑格。低架侧身拖剑的起手式。

### 石狮（兽）——对应格斗家

- 门前的石狮子活了过来，直立的人形兽：宽矮、桶胸，石青色的卷毛鬃，灰石身体带裂纹，红项圈和铜铃。
- 武器：石绣球流星锤（雄狮爪下的绣球，变成拴铁链的石球），近身抱着砸，远一点抡链子。备选：大锤、石墩。
- 轮廓：宽矮。主色：石青 + 石灰。
- 缺：守护的地方。它守的宅门已被墨蚀吞掉。
- 定稿：石青大鬃毛蓬成一团、龇牙瞪眼的狮脸；灰青石皮肤带裂纹，肌肉块很大；
  肩上金色卷草护肩，颈下两颗金铃；红腰围、正中一颗大铜铃，红色前裆片带金色回纹；石青卷尾。
  武器是一颗带裂纹的大石球，铁链缠在另一只拳头上。
- 还要细化：石球现在是光面，要刻上绣球的镂空纹和彩带，才能看出是"狮子绣球"。

### 墨斗（器）——对应神枪手

- 画圣界画（营造图样）里的一件机关木偶，墨蚀后自己站了起来。自主行动，没有操纵者。
- 性格：一板一眼，照图纸理解世界。
- 外形：全身榫卯、不用一颗钉子；斗拱叠成肩甲；木纹里流着发光的墨线（墨就是它的能源）；
  身上贴黄纸符箓写着部件编号。头是榫卯木匣，木面具上没有眼睛，只有一道发光墨线。
  一条胳膊是虎蹲炮，另一只木手拿墨斗；背上是斗拱叠成的一窝蜂火箭箱。
- 不要蒸汽、管道、西式齿轮、铆钉（避免蒸汽朋克）。
- 轮廓：中等身高、左右不对称（一边粗炮、一边细手、背上一座小楼）。主色：桐油木黄 + 金漆 + 青铜，藤黄流苏。
- 招式：连弩速射；虎蹲炮（后坐力把自己往后推）；**墨斗弹线**（地上弹一道墨线当陷阱，招牌技）；
  木鸢、木牛炮台；大招火龙出水或一窝蜂齐射；炮的后坐力跳。射击前空中先画出界画式的尺规辅助线。
- 缺：眼睛。画圣没来得及"点睛"，它要找到画圣请他点睛（想成为"活的"）。
- 定稿：方形木头匣，正面一块圆形木面具，没有五官，只有一道墨线；头戴黑漆宋式幞头
  （前低方、后隆起，两条长直翅从两侧平伸，翅宽超过肩宽，金色描边）；斗拱叠成的肩甲带红色端头；
  胸口木窗格 + 铜饕餮扣；红腰带上挂黄纸符箓。右臂是虎蹲炮，炮口是铜铸镇宅虎头
  （卷云鬃毛一圈、额头"王"字、张口吐炮膛），炮管下两只爪形支脚；左手握木墨斗盒，墨线一路拖到地上、
  滴着墨点；背上木箱插一排竹火箭筒，红色箭头。
- 定稿和设定还差的地方：背箱还是普通木箱，没做成斗拱叠出的小楼顶；身上的发光墨线纹路和藤黄流苏也还没画；
  头匣偏高，帽子和头匣连成一块。做 3D 或骨骼时一并补上。
- 制作经验：只用文字生成，墨斗总会变成机器人或机甲。可行的流程是：SVG 摆草图 → edit_image 上色 →
  本地手画要改的部位 → FLUX 轻量过一遍统一画风。FLUX 改图时紧贴原图结构，在原图上加的小标记会被抹掉；
  要换掉整个部件，就先单独用文字生成那个部件，贴回去再整体过一遍（虎头就是这样换的）。
